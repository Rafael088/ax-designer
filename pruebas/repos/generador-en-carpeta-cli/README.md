# generador-en-carpeta-cli

Repo de mentira para `pruebas/rubrica/evaluar.test.ts`: reproduce el patrón que la auditoría
sobre el propio axd encontró (`axd auditar .`) — un generador de código que vive
en una carpeta llamada `cli/` (porque genera un CLI para el repo objetivo) y cuyo `switch`
enumera tipos internos, no comandos. El único verbo de verdad es el de `src/cli/main.ts`.
